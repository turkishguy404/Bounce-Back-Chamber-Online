# Bounce-Back-Chamber-Online
Leave a piece of yourself behind. Then use it to get out.  Bounce Back is a small physics puzzle-platformer about cloning yourself to solve problems.

# How to play

W/Space to jump.

A to go left.

D to go right.

R to clone.

F for rope swinging.
